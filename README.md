# eByte — Fullstack App (Node.js + React + Vite)

Este projeto é composto por **backend em Node.js** e **frontend em React (Vite)**, compartilhando um único `node_modules` na raiz.

---

## Rodando em ambiente local

Na raiz do projeto, execute:

npm run dev

## Gerando build de produção

Na pasta /frontend, execute:

npm run build

## Upload pro Git

git add .
git commit -m "Atualização"
git push
